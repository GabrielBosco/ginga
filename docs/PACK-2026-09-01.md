# Pack de melhorias - 01/09/2026

Este pack preserva as funcionalidades existentes do Ginga e aplica correcoes/adicoes de forma compativel com a serie 0.4.8.

## Cadastro e privacidade

- cadastro de conta humana passa a exigir data de nascimento;
- idade minima de 16 anos validada no Web e novamente na API;
- coluna `User.birthDate` e adicionada de forma idempotente no bootstrap para bancos existentes;
- novas rotas publicas `/terms` e `/privacy`;
- Termos de Uso e Politica de Privacidade ficam acessiveis a partir do login/cadastro e da Central de Ajuda;
- `robots.txt` e `sitemap.xml` adicionados para as paginas publicas.

## Knowledge / layout

- corrigido o corte vertical da pagina Knowledge em desktop;
- header, seletor de publico, sidebar e artigo passam a respeitar a altura real da viewport;
- sidebar e conteudo possuem rolagem independente sem estourar a janela;
- ajuste considera a titlebar customizada do Desktop Windows.

## Desktop

- titlebar Windows reduzida de 32 px para 28 px;
- botoes minimizar/maximizar/fechar ficaram menores e visualmente mais limpos;
- mantidos drag, duplo clique para maximizar e todos os IPCs existentes.

## Voz e microfone

- novo controle funcional de Sensibilidade do microfone em Configuracoes > Voz e video;
- 50% preserva o ganho original; acima disso amplifica vozes baixas em tempo real;
- sensibilidade tambem aparece no teste do microfone;
- preferencia e persistida localmente e reaplicada ao reconectar/reativar o microfone;
- processadores externos existentes nao sao substituidos.

## Compartilhamento de tela

- qualidade/FPS agora tambem configuram os parametros de publicacao do LiveKit, nao apenas a captura;
- 1080p/60 recebe bitrate superior e prioridade alta;
- `maintain-framerate` prioriza movimento fluido em jogos/video;
- VP8 e usado como codec base compativel;
- troca de janela preserva a transmissao e reaplica constraints de resolucao/FPS;
- fluxo de chamada direta usa o mesmo ajuste do fluxo de sala de voz.

## Soundboard

- upload permite selecionar o trecho do audio com inicio/fim e pre-escuta;
- metadados de corte sao armazenados sem quebrar sons antigos;
- playback respeita o trecho escolhido;
- tentativa explicita de desbloquear audio do navegador no clique do usuario;
- audio do Soundboard nao nasce mutado e usa o dispositivo de saida selecionado;
- endpoint de audio passa a aceitar `Range`, melhorando seek/preload quando o trecho comeca no meio do arquivo.

## Service Worker

- cache shell rotacionado para que clientes recebam as alteracoes de interface;
- mantida a CSP corrigida do `/sw.js`, incluindo `connect-src 'self'`.

## Deploy recomendado

No servidor:

```bash
cd /opt/ginga
docker compose build api web
docker compose up -d --no-deps api web
docker compose ps
```

Depois valide:

```bash
curl -fsS https://ginga.opik.net:3090/api/health
curl -sSI https://ginga.opik.net:3090/sw.js | grep -i content-security-policy
```

O header do Service Worker deve continuar contendo `connect-src 'self'`.

Para o Desktop, gere um novo instalador apenas quando quiser distribuir a nova titlebar:

```bash
./build-win.sh
```

## Checklist manual sugerido

1. criar uma conta com menos de 16 anos e confirmar o bloqueio;
2. criar uma conta 16+ e concluir a verificacao de e-mail;
3. abrir `/terms`, `/privacy` e `/knowledge` em Web e Desktop;
4. entrar em voz, ajustar Sensibilidade e testar fala baixa;
5. tocar Soundboard no proprio cliente e em outro participante;
6. adicionar um som, escolher um trecho do meio e usar `Ouvir trecho`;
7. transmitir 1080p/60 e conferir movimento/estatisticas de rede;
8. trocar a janela compartilhada sem encerrar a transmissao;
9. conferir minimizar/maximizar/fechar e drag da titlebar no Windows.
