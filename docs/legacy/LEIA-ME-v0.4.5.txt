GINGA 0.4.5 - RELEASE WINDOWS + LINUX
====================================

1) APLICAR O SOURCE

cd /root/Ginga-v0.4.5-WINDOWS-LINUX-source
./scripts/apply-update-safe.sh "$(pwd)"

2) VALIDAR WINDOWS + LINUX

cd /opt/ginga-build
./scripts/pre-release-check.sh 0.4.5 --all

3) PUBLICAR

Opcao recomendada - Windows + Linux x64 + ARM64:
./release-all.sh 0.4.5 --all

Somente Windows:
./release-win.sh 0.4.5

Somente Linux x64:
./release-linux.sh 0.4.5 --x64

Somente Linux ARM64:
./release-linux.sh 0.4.5 --arm64

Linux x64 + ARM64:
./release-linux.sh 0.4.5 --all

OBSERVACOES
- Nao use --init-key se ja existem clientes Windows publicados. Preserve secrets/update-signing/private.pem.
- O feed Windows precisa estar abaixo de 0.4.5. Se estiver em 0.4.4, a 0.4.5 e valida.
- O fix do electron-builder 26.15.3 esta mantido: packageName fica em build.deb/build.rpm, nao em build.linux.
- apply-update-safe.sh preserva .env, updates/, secrets/ e artefatos publicados.
