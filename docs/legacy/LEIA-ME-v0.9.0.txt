GINGA 0.9.0 - ULTIMATE COMMUNITY / SOCIAL / DESKTOP

Pacote SOURCE completo em cima da 0.4.0. Nao inclui node_modules, .exe, .env real ou private.pem.

DESTAQUES
- Mantem o fix Desktop 0.4.0 (sandbox/preload/zoom) que evita o Electron cair no layout Web.
- Personalizacao 0.9 de servidor: Areas, emojis, stickers, onboarding, salas dinamicas, badges e seguranca.
- Perfil Social 0.9: aniversario opcional, badge, decoracao, expiracao, perfil compacto/reduced motion.
- Backend de perfil por servidor, notas privadas, mutuals, drafts sincronizados e historico de edicoes.
- Anti-raid/quarentena/filtros de links-convites/mencoes/repeticao e auto-timeout opcionais.
- PWA instalavel; /api e /updates nunca entram no cache do Service Worker.
- Desktop com deep link ginga://invite/, iniciar com Windows e crash report best-effort.
- SDK Python existente + novo SDK JavaScript/TypeScript 0.9.0.
- Admin health-v2 e relatorios recentes de crash.

APLICACAO SEGURA
1. Extraia o ZIP, por exemplo em /root/Ginga-v0.9.0-ULTIMATE-source
2. Confirme:
   test -s /opt/ginga/.env && echo ENV_OK
   test -s /opt/ginga-build/secrets/update-signing/private.pem && echo CHAVE_OK
3. Rode:
   cd /root/Ginga-v0.9.0-ULTIMATE-source
   ./scripts/apply-update-safe.sh "$PWD"
4. Publique:
   cd /opt/ginga-build
   ./release-win.sh 0.9.0

NAO use --init-key se os clientes atuais ja usam a chave existente.
