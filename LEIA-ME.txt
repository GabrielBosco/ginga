Ginga 0.1.0 - suporte SMTP/Gmail para verificacao de e-mail

Arquivos alterados:
- apps/api/package.json (Nodemailer)
- apps/api/src/routes/registrationVerification.ts (provider smtp + resend)

No /opt/ginga/.env configure:
EMAIL_VERIFICATION_REQUIRED=true
EMAIL_PROVIDER=smtp
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=ginga.noreply@gmail.com
SMTP_PASSWORD="SENHA_DE_APP_SEM_ESPACOS"
EMAIL_FROM="Ginga <ginga.noreply@gmail.com>"

Depois:
cd /opt/ginga
docker compose build --no-cache api
docker compose up -d api
docker compose logs --tail=100 api
curl http://127.0.0.1:3090/api/auth/registration-policy
