# Ginga — JavaScript / TypeScript

Para bots em Node.js:

```bash
npm install socket.io-client dotenv
```

Use `fetch` nativo no Node.js 20+ para chamadas HTTP e `socket.io-client` para eventos em tempo real. Tokens devem permanecer somente no backend.

Consulte a Base de Conhecimento do **Portal do Desenvolvedor** para o fluxo:

```text
Aplicação → Bot → Permissões → Instalação
```
