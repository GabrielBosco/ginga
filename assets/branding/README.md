# Identidade visual do Ginga

Arquivos principais desta identidade:

- `ginga-brand-board.png`: prancha visual com a direção da marca;
- `apps/web/public/ginga-mark.svg`: marca principal usada na Web e no login;
- `apps/web/public/favicon.svg`: favicon e base para ícones.

Use esta identidade como referência para login, tela de abertura, atualizador, Desktop, Android e futuras peças do projeto.
